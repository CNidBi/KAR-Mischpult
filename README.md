# KAR-Mischpult

Web-App zum Koordinations-Anforderungs-Regler (KAR) nach Neumaier für den Sport-LK.
Startseite mit Einstiegs- und Vollversion, offline nutzbar, auf dem iPad über Safari → Teilen → „Zum Home-Bildschirm“ installierbar.
Keine Anmeldung, Eingaben bleiben auf dem Gerät.

Nach Änderungen in `sw.js` die `VERSION` hochzählen, damit installierte Apps das Update übernehmen.
